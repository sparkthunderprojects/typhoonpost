# Typhoonpost Documents: full feature catalogue

Companion to `word-processor-plan.md`. One bullet is one feature. Phase tags: **P1** personal documents, **P2** page layout, **P3** review, **P4** Business, **P5** later. Where a feature is limited by the encryption rules, the limit is written next to it. Anything marked **Not planned** is listed on purpose so the gap is visible.

All features run in the browser. Nothing here sends document text to a server.
